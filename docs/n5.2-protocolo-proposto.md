# N5.2 — proposta aditiva para o contrato

Proposta no PR #33, dentro da implementação solicitada por DTRZ.
Sem alteração do contrato canônico ou dos comandos existentes.
Cliente novo trata motor antigo como narração indisponível.

- `speech.voices`, sem parâmetros: `{provider, available, voices:[{id,name,language,available}]}`.
- `speech.say`, `{text,profile}`: `{jobId,position}`. Texto não vazio, até 8.000
  caracteres; fila de até 32 trabalhos, um processo por vez.
- Perfil de narração `en-en2` (inglês); referência fixa definida pelo provider,
  sem aceitar arquivo arbitrário pelo protocolo.
- Eventos existentes admitem `kind:"narration"`. Progresso por etapas com
  `fraction`, `etaSeconds:null` e `stage` opcional; não é porcentagem de tokens.
- `job.done`: `{path,duration,profile,provider}` e métricas opcionais.
  `job.error`: código estável e mensagem pt-BR. `job.cancel` cobre fila e processo.
- Editor verifica WAV por `media.probe`, insere por `timeline.set` existente
  e só substitui o clipe após regeneração bem-sucedida. Arquivo anterior preservado.
- Texto/perfil de regeneração ficam no projeto local, fora de `timeline.set`.

Sem rede na inferência, `unsafe`, dependências Rust novas ou servidor Python.
